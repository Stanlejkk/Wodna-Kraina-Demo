# Wodna Kraina – Demo

Demo strony internetowej dla łowiska wędkarskiego "Wodna Kraina" w Wildze.

## Tech Stack

- Next.js 16 (App Router), TypeScript
- Tailwind CSS v4
- Dane mockowane (bez API keys, bez zmiennych env)

## Uruchomienie

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npx vercel --yes
```

Nie są potrzebne żadne zmienne środowiskowe.

## Strony

- `/` – Strona główna (hero, akweny, ryby, cennik, mapa)
- `/o-nas` – O łowisku
- `/gatunki-ryb` – Gatunki ryb
- `/oplaty` – Cennik + system rezerwacji
- `/galeria` – Galeria zdjęć (placeholdery)
- `/regulamin` – Regulamin łowiska
- `/kontakt` – Kontakt + formularz
